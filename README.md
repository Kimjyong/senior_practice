# 어르신 디지털 생활 도우미 📱

> **실수와 결제 두려움 없는 시니어 맞춤형 스마트폰 사용법 및 3대 생활 서비스(병원·기차·키오스크) 가상 실습 웹 플랫폼**

---

## 📖 프로젝트 소개

본 프로젝트는 디지털 소외 계층인 어르신들이 스마트폰 기초 사용법과 일상 생활 필수 서비스(병원 예약, KTX 기차표 예매, 무인 식당 키오스크)를 실제 결제나 실수에 대한 두려움 없이 안전하게 학습하고 실습할 수 있는 **100% 가상 샌드박스 웹 에듀케이션 플랫폼**입니다.

- **접근 장벽 제로**: 회원가입, 로그인, 본인인증, 앱 설치 불필요
- **심리적 안전성**: 100% 모의 데이터로 운영되며 실제 결제/예약 API와 연동되지 않는 완전 무료 실습 환경
- **시니어 전용 UX**: 본문 20px 이상, 60px 이상 대형 터치 버튼, 고대비 컬러, 단계별 글씨 크기 조절, 한국어 음성 안내(TTS) 지원

---

## ✨ 주요 기능

### 1. 단계별 스마트폰 기초 배우기
- **카카오톡 안부 메시지 보내기**: 대화방 찾기, 입력창 터치, 전송 버튼
- **사진 찍고 가족에게 보내기**: 카메라 촬영, 더하기(+) 메뉴, 앨범 선택, 사진 전송
- **문자 메시지 확인 및 답장**: 문자함 확인, 스미싱 의심 링크 주의 안내, 안전한 답장 작성
- **필요한 앱(어플) 설치하기**: Play 스토어 돋보기 검색, 앱 선택, 초록색 설치 버튼

### 2. 필수 3대 디지털 생활 서비스 가상 체험
- **🏥 병원 진료 예약**: 6대 진료과목, 희망 날짜, 시간 선택 및 가상 진료 예약증 발급
- **🚄 KTX 기차표 예매**: 출발역/도착역 지정, 어르신 30% 경로 할인, 좌석 선택, 모바일 승차권(QR) 발권
- **🍔 무인 키오스크 주문**: 메뉴 선택, 수량 조절, 매장/포장 선택, 카드 결제 시뮬레이션 및 번호표(072번)/영수증 출력

### 3. 고령층 맞춤형 특화 편의 기능
- **글씨 크기 3단계 전환**: [보통 (20px)] / [크게 (24px)] / [가장 크게 (28px)]
- **한국어 음성 안내 (TTS)**: Web Speech API를 활용해 설명 문구를 소리로 읽어주는 기능
- **디지털 생활 자립 인증서**: 실습 달성률에 따른 배움 도장 및 수료 인증서 제공

## 🚀 로컬 실행 방법

Node.js 환경에서 아래 명령어를 실행하여 로컬에서 바로 실행할 수 있습니다.

```bash
# 1. 의존성 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000` 또는 터미널에 표시된 주소로 접속합니다.

## 🌐 무료 배포 방법 (100% Free Hosting)

### 1. Vercel 배포 (가장 추천 - 1분 소요)
1. [Vercel](https://vercel.com)에 로그인 (GitHub 계정으로 연동)
2. **Add New...** → **Project** 클릭
3. 이 GitHub 저장소를 선택
4. Framework Preset을 **Vite**로 확인 후 **Deploy** 버튼 클릭
5. 몇 초 만에 무료 HTTPS 도메인(`*.vercel.app`)이 생성되어 즉시 접속 가능합니다!

### 2. GitHub Pages 배포
`vite.config.ts`의 `base` 설정을 저장소 이름으로 맞춘 후 GitHub Pages로 무료 호스팅할 수 있습니다.
