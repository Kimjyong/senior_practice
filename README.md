# 어르신 디지털 생활 도우미 (Senior Digital Life Helper) 👵👴📱

> **"실수와 결제 두려움 없는 시니어 맞춤형 스마트폰 사용법 & 3대 필수 생활 서비스(병원·기차·키오스크) 가상 실습 웹 에듀케이션 플랫폼"**

한국 사회의 고령화와 무인화·디지털 전환(Digital-Only)에 발맞추어, 70대 이상 어르신들이 스마트폰 조작 실수나 금전적 결제 위험 없이 안전하게 스마트폰 기초와 생활 필수 디지털 서비스를 연습할 수 있도록 제작된 **100% 가상 샌드박스 웹 애플리케이션**입니다.

---

## 🌟 주요 기능

### 1. 단계별 스마트폰 기초 배우기
- **카카오톡 메시지 보내기**: 자녀 대화방 찾기, 글자 입력칸, 노란색 종이비행기 전송 버튼
- **사진 촬영 및 가족에게 보내기**: 카메라 셔터 찰칵, 대화방 더하기(+) 버튼, 앨범 아이콘, 사진 전송
- **문자 메시지 확인 및 안전한 답장**: 안 읽은 문자 확인, 의심스러운 링크 주의 팁, 감사 답장 발송
- **필요한 앱 검색 및 설치하기**: Google Play 스토어 돋보기 검색, 코레일톡 앱 선택, 초록색 [설치] 버튼
- **인터랙티브 가상 스마트폰**: 화면 안의 버튼을 직접 터치하며 배우는 모의 실습 환경

### 2. 디지털 생활 서비스 가상 체험 (3대 필수 서비스)
- 🏥 **동네 병원 진료 예약**: 6대 진료과목(내과, 정형외과 등), 날짜, 시간 선택 및 가상 모바일 진료 예약증 발급
- 🚄 **KTX 기차표 예매**: 출발/도착역 선택, 어르신 30% 경로 할인 자동 계산, 창가/통로 좌석 선택 및 모바일 승차권(QR) 발권
- 🍔 **식당 무인 키오스크 주문**: 메뉴 담기, 60px 이상 대형 수량(+/-) 조절, 매장/포장 선택, 신용카드 모의 결제 및 대기번호(072번) 영수증 출력

### 3. 고령층 맞춤형 UI/UX 체계
- **시원한 글씨 크기 3단계 조절**: [보통 (20px 이상)] / [크게 (24px)] / [가장 크게 (28px)]
- **🔊 친절한 음성 안내 (TTS)**: 상단 소리 켜기/끄기로 모든 안내 문구를 음성으로 청취 가능
- **100% 무타자 터치 인터페이스**: 복잡한 키보드 입력 없이 큼직한 버튼 터치만으로 모든 조작 완수
- **100% 무료 & 안심 보장**: 회원가입, 로그인, 실제 결제가 전혀 발생하지 않는 안전한 모의 실습
- **🏅 배움 도장 & 디지털 생활 자립 인증서**: 실습을 마칠 때마다 도장이 찍히며 성취감 고취

## 🚀 로컬 실행 방법 (Local Development)

```bash
# 1. 저장소 클론
git clone <저장소-URL>
cd senior-digital-helper

# 2. 패키지 설치
npm install

# 3. 개발 서버 실행
npm run dev

# 4. 프로덕션 빌드 테스트
npm run build
```

## 🌐 무료 배포 방법 (Free Deployment Guide)

### 방법 1. GitHub Pages (자동 배포, 100% 무료)
이 저장소에는 `.github/workflows/deploy.yml`이 이미 포함되어 있습니다.
1. GitHub 저장소 상단 **Settings** 메뉴로 이동합니다.
2. 왼쪽 사이드바에서 **Pages**를 클릭합니다.
3. **Build and deployment > Source** 항목을 **`GitHub Actions`**로 선택합니다.
4. 코드를 `main` 브랜치에 푸시하면 몇 분 내로 `https://<내아이디>.github.io/<저장소이름>/`에 무료로 배포됩니다!

### 방법 2. Vercel 또는 Netlify (원클릭 무료 배포)
1. [Vercel](https://vercel.com) 또는 [Netlify](https://www.netlify.com)에 GitHub 계정으로 로그인합니다.
2. **Add New Project**를 누르고 이 GitHub 저장소를 선택합니다.
3. 설정 변경 없이 **Deploy** 버튼을 누르면 1분 만에 전 세계에 무료로 배포됩니다.
